# 程导览 设计文档

> 品牌「程导览」（副标 TRIP GUIDE）· 工程名 `trip-guide` · 前后台共用 `public/spots`

## 仓库

```
trip-guide/                               # 仓库根即应用（包名 trip-guide）
├── public/spots/                         # 唯一已发布数据源（catalog + 各景点文件）
├── .trash/spots/                         # 管理页删掉的景点包与图片（搬回 public/spots 即恢复）
├── src/lib/tourPackage.ts
├── docs/
└── README.md
```

## 数据

| 用途 | 来源 |
|---|---|
| 前台列表 / 导览 | `public/spots/catalog.json` + `{id}.json` |
| 发布后台列表 | **同一 catalog**；另附尚未发布的本地草稿；每行额外读一次 `{id}.json` 拿节点数（有本地草稿就用草稿的节点） |
| 编辑中草稿 | `localStorage`（`trip-guide:drafts:v1`） |
| 点「发布」 | 写入本应用 `public/spots/` |
| 点「删除」（已发布） | 包与图片目录移进 `./.trash/spots/{id}/`，并从 catalog 摘掉；纯本地草稿只删 `localStorage` |
| 点「恢复」（列表底部「已删除」区） | 从 `./.trash/spots/` 搬回 `public/spots/`，catalog 按 `publishedAt` 插回原位置 |

导览模式是包顶层的可选字段 `mode: 'checkin' | 'story'`（缺省 = 打卡）：打卡按 `spots` 顺序线性走完，故事按顶层 `story` 那张**去向表**分支走。`PACKAGE_SCHEMA_VERSION` 不动，两个字段都是 optional，存量包照旧。**catalog 的每个 item 也带一份 `mode`**（发布时由包写入；更早的条目没有这个字段，前台按「打卡」兜底），首页列表据此打「故事 / 打卡」标。详见 `docs/note/02-故事模式-分支叙事.md`。

## 发布流程

1. **确定范围**（`/publish/:id`）：名称、城市、**导览模式（打卡 / 故事）**；高德检索景区与周边地点 → 勾选候选；「相对位置」画布看主景点与已选地点的方位
2. **地点与内容**（`/publish/:id`，地图选点工作台）：用勾选结果生成节点（阶段二还没有节点时，点第 1 步的「下一步」就会自动生成）→「按名称定位」用高德刷新坐标 → 拖标记校准 → 拖绿标定游客起点；故事模式另在选中节点上连**分支**（去向多选 / 设为入口 / 结局），列表头显示 `入口 / 结局 N 个 / 孤立 N 个`，有孤立或悬空就发布不了；全部节点写过文案后才可发布
3. **内容创作**（`/publish/:id/content`，独立页、不挂地图）：「AI 生成讲解」按节点逐个写文案、并顺带写好景点简介 → 逐条改文案 / 传图（故事模式多一张**分支文案**卡：每个去向的选项文案与一行小字、结局节点的结局标题）→ 发布；点「调整地点」退回第 2 步重新拖坐标

**坐标与分支在第 2 步定、文案在第 3 步写**，两边互不覆盖（重跑 AI 不动坐标、不动分支，重定位不动文案）。详见 `docs/note/01-发布编辑器-地图选点与内容创作.md`。

## 路由

`/` 前台（页首副题「点击进入沉浸式地图导览，边走边听讲解」**同一行右侧接着图例**：色标就是卡片右下角那个小标本身（`ModeTag`，故事实心、打卡描边），标后面跟一句它的意思——「故事：分支探索，路口自己选下一步」「打卡：游遍景点，按顺序走完」；图例色标与卡片小标是同一个组件，改一处两边一起变；这一行 `flex-wrap`，窄屏图例整体折到下一行；「全部景点」那一行只有标题和靠右的 `N 个`） · `/tour/:id` 导览（按包的 `mode` 分发：打卡页 / 故事页，路径不变；两个页面的页头都在景点名后带一个模式小标） · `/publish` 后台（**一行一个景点、无顶部大图**：缩略图 + 名称 + `ModeTag` + `已发布 / 草稿` + 一行简介 + 最多三行的节点信息「N 个节点 · 已编辑 x / 未编辑 y · …」+ 删除；节点信息第三段**按模式分叉**——打卡包是 `节点名 → 节点名 → …`（顺序就是它的真相），故事包是每个分叉点一行 `入口 猴山 → 新狼馆 / 本土物种保育区 / 细尾獴馆` 加末行 `结局 …`（没有分叉才回落链条）；删除走行内二次确认，已发布景点移入 `./.trash/spots/{id}/`，删除内容列在页面底部「已删除」区、点「恢复」即搬回 `public/spots`） · `/publish/:id` 编辑器（阶段一 / 二）· `/publish/:id/content` 内容创作
