>
> 品牌 mark（2026-10-17 换）：深底 `#111827` 圆角方（36px / `rounded-[11px]`），里面是一枚**定位针压在虚线路径末端**（针体白、针孔透出底色、路径用 `strokeDasharray="0.1 4.4"` + 圆头画成一串点）—— 原来是「折线 + 首尾两点」，单看像股票走势图，故换掉。同一版矢量也做了 `public/favicon.svg`（48×48、`rx=14` 的深底方 + 同一枚针，居中 24 单位），所以页头 logo 与浏览器标签页图标是同一套；改一处记得另一处一起改。

## 数据

| 用途 | 来源 |
|---|---|
| 前台列表 / 导览 | `public/spots/catalog.json` + `{id}.json` |
| 发布后台列表 | **同一 catalog**；另附尚未发布的本地草稿；每行额外读一次 `{id}.json` 拿节点数（有本地草稿就用草稿的节点） |
| 编辑中草稿 | `localStorage`（`trip-guide:drafts:v1`） |
| 点「发布」 | 写入本应用 `public/spots/` |
| 点「删除」（已发布） | 包与图片目录移进 `./.trash/spots/{id}/`，并从 catalog 摘掉；纯本地草稿只删 `localStorage` |
| 点「恢复」（列表底部「已删除」区） | 从 `./.trash/spots/` 搬回 `public/spots/`，catalog 按 `publishedAt` 插回原位置 |

导览模式是包顶层的可选字段 `mode: 'checkin' | 'story'`（缺省 = 打卡）：打卡按 `spots` 顺序线性走完，故事按顶层 `story` 那张**去向表**分支走。`PACKAGE_SCHEMA_VERSION` 不动，两个字段都是 optional，存量包照旧。**catalog 的每个 item 也带一份 `mode`**（发布时由包写入；更早的条目没有这个字段，前台按「打卡」兜底），首页列表据此打「故事 / 打卡」标。详见 `docs/note/02-故事模式-分支叙事.md`。

**游客头像**也是包顶层的可选字段 `visitorAvatar`（图片路径，两种模式共用）：内容创作页两张卡上都能传一张图，传了就写进包、导览页地图上那枚游客标记换成它；没传整份包不出现这个字段，前台照旧用内置吉祥物。

## 发布流程

1. **确定范围**（`/publish/:id`）：名称、城市、**导览模式（打卡 / 故事）**；高德检索景区与周边地点 → 勾选候选；「相对位置」画布看主景点与已选地点的方位
2. **地点与内容**（`/publish/:id`，地图选点工作台）：用勾选结果生成节点（阶段二还没有节点时，点第 1 步的「下一步」就会自动生成）→「按名称定位」用高德刷新坐标 → 拖标记校准 → 拖绿标定游客起点；故事模式另在选中节点上连**分支**（去向多选 / 设为入口 / 结局），列表头显示 `入口 / 结局 N 个 / 孤立 N 个`，有孤立或悬空就发布不了；全部节点写过文案后才可发布
3. **内容创作**（`/publish/:id/content`，独立页、不挂地图，**按 `mode` 分两张页**）：打卡模式＝「景点简介 / 节点内容」两张卡，页头按钮是「AI 生成讲解」（**按段拆成多次请求**：景点简介一段 + 每个节点各一段，每段写完即刻落盘、忙时那条 toast 上是进度条 +「3/4」这类步骤计数；失败的那一段不动原文案 → 逐条改文案 / 传图）→ 发布；故事模式＝「**故事结构**（可点的结构图，入口在最左、结局虚线收口）/ **前情提要** / 节点内容 / **这个节点的去向**」四张卡——去向卡里能加删去向、设为入口、标为结局，每个去向写选项文案与一行小字、结局节点写结局标题；页头中心第一行是景点名 + 紧挨着可编辑的**故事名**（进发布包的 `story.title`，导览页也显示它）；页头按钮是「**AI 生成内容**」，**左边紧挨一个「创作方向」输入框**（placeholder「输入故事创作方向」，点一下就地展开一块完整编辑区、点空白或 Esc 收起；写主线 / 语气 / 意象，只喂 AI，草稿态字段不进发布契约），点一次默认就把**故事名** + 开场（前情提要）+ 情节 + 选项文案 + 结局标题都写了，**用的是故事专用的提示词**（第二人称、情节前后相接＝上一站的旁白会被喂进下一段、严格照创作方向写），**生成按段拆成多次请求**（故事名与前情提要一段 + 每个节点各一段，勾了结构再多一次），每段写完即刻落盘、失败的那段不动原文案，忙时那条 toast 上是进度条 +「3/4」这类步骤计数；点它会先弹一个小面板，**逐项勾这一趟要 AI 写哪些部分**（故事名 / 前情提要 / 情节 / 选项文案 / 结局标题默认全勾，**「修改故事结构」默认不勾**，一个都没勾时「开始生成」禁用，只写勾上的那几项）；勾了结构才会让 AI 连去向 / 入口 / 结局一起重排（节点与坐标始终不动，重排后选项文案按新去向重新对齐），不勾就只写文案、结构一行不动。两页页头都有「调整地点」退回第 2 步；页头那颗蓝按钮 2026-10-17 由「发布」改为「**预览**」（发布动作统一收到 `/publish/:id/preview` 里，见下面「路由」）

**坐标与分支在第 2 步定**：重跑 AI 不动坐标与关系（只在已连过线或真分叉的节点上写选项文案）、重定位不动文案。打卡页行为与拆分前一字不差。详见 `docs/note/03-内容创作页-打卡与故事分页.md`。

## 路由

`/` 前台（页首副题「点击进入沉浸式地图导览，边走边听讲解」**同一行右侧接着图例**：色标就是卡片右下角那个小标本身（`ModeTag`，故事实心、打卡描边），标后面跟一句它的意思——「打卡：游遍景点，按顺序走完」「故事：分支探索，路口自己选下一步」（打卡在前）；图例色标与卡片小标是同一个组件，改一处两边一起变；这一行 `flex-wrap`，窄屏图例整体折到下一行；「全部景点」那一行只有标题和靠右的 `N 个`） · `/tour/:id` 导览（按包的 `mode` 分发：打卡页 / 故事页，路径不变；两个页面的页头都在景点名后带一个模式小标；故事页进来先给一个「开始」遮罩（入口节点名 + 包里的**前情提要**，正是内容页那张卡写的那段，让开场先有个交代）；页头那颗胶囊里，景点名下面再带一行小字**故事名**（`story.title`，没起名就只有景点名一行），遮罩那行小字也跟着变成「故事名 · 入口」，点它才播入口节点，也是为了绕开浏览器的自动播放限制；走到结局节点、该节点口播讲完再压一块**结算画面**（结局标题 + 本趟足迹 + 重新开始 / 自由漫游，点空白关掉就回到左下角那张结局卡）） · `/publish` 后台（**一行一个景点、无顶部大图**：缩略图 + 名称 + `ModeTag` + `已发布 / 草稿` + 一行简介 + 最多三行的节点信息「N 个节点 · 已编辑 x / 未编辑 y · …」+ 删除；节点信息第三段**按模式分叉**——打卡包是 `节点名 → 节点名 → …`（顺序就是它的真相），故事包是 `入口 X` + 每个分叉点一行 `澳洲区 → 考拉馆 / 新虎园` + 末行 `结局 …`（入口自己就是分叉点时并进那一行；没有分叉才回落链条）；删除走行内二次确认，已发布景点移入 `./.trash/spots/{id}/`，删除内容列在页面底部「已删除」区、点「恢复」即搬回 `public/spots`） · `/publish/:id` 编辑器（阶段一 / 二）· `/publish/:id/content` 内容创作（**按包的 `mode` 分发**：打卡＝原样那一页；故事＝结构图打头，见上面发布流程第 3 步）· `/publish/:id/preview` 预览（**发布只剩这一个入口**：三个编辑屏页头的「发布」都换成「预览」，跳到这页用 `toSelfContainedPackage` 把草稿拼成自包含包、按 `mode` 直接渲染前台那一页（不写 `public/spots`，所以草稿没写完也能进来看），右下角浮一条 `预览中 · 退出预览 · 去前台看 · 发布`；门控（节点文案写全 + 故事图无 error）挂在预览页的「发布」上；`?from=map|content` 决定「退出预览」回哪个编辑屏）
